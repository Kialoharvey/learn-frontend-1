# Reflection

## What did you ask the AI to do?

I used AI to help me build a React frontend that connects to my PNG Culture REST API. I asked for help creating signup, login, view all posts, and view one post pages.

## What did it do well?

AI explained React concepts, fetch requests, routing, JWT storage, and helped debug errors. It provided examples that I could understand and modify.

## What did it get wrong or what did you have to fix?

Sometimes AI gave code that had small mistakes or missing imports. I had to debug issues with routing, CORS, empty pages, and duplicate code in app.js.

## What did you learn from working with it?

I learned how React components work, how to use React Router, how to send requests to an Express API, how JWT authentication works, and how to troubleshoot problems when code does not work.
