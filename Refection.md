# Reflection

## What did you ask the AI to do?

I used AI to help me build a React frontend for my PNG Culture and Tradition project. I asked for help creating pages for signup, login, viewing all culture posts, viewing a single post, creating posts, editing posts, deleting posts, viewing comments, viewing individual comments, and creating comments. I also used AI to improve the design and appearance of the website.

## What did it do well?

AI explained React concepts, React Router, fetch requests, JWT authentication, and how to connect the frontend with my Express and MongoDB API. It helped me create forms, implement CRUD operations, debug errors, and improve the overall appearance of the website with CSS styling and a cultural background image.

## What did it get wrong or what did you have to fix?

Sometimes AI generated code with small mistakes such as missing imports, duplicate code, incorrect routes, and token-related issues. I had to debug problems involving navigation, CORS, routing, expired JWT tokens, and errors that appeared when updating or deleting posts. I also had to adjust some CSS and component layouts to achieve the design I wanted.

## What did you learn from working with it?

I learned how React components work, how to use React Router for navigation, how to send HTTP requests to an Express API, how JWT authentication works, and how to perform CRUD operations from the frontend. I also learned how to troubleshoot errors, organize React components, and improve the user experience through CSS styling and responsive design. Working with AI helped me better understand how the frontend and backend communicate in a full-stack application.
